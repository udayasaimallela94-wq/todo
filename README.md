# Daymark Todo

A responsive todo list built with Next.js App Router. Create tasks with notes, due dates, projects, and priorities; search, complete, and remove tasks. Your list is saved in this browser with `localStorage`.

## Requirements

- Node.js 18.18 or newer
- npm

## Run locally

```powershell
cd todo
npm install
npm run dev
```

Open the local URL printed by Next.js (usually `http://localhost:3000`).

## Production build

```powershell
npm run build
npm start
```

Data is stored per browser and is not synced to an account or shared across devices.
